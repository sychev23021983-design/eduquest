# Промпты для новых чатов

## Продолжение разработки

```text
Мы продолжаем работу над EduQuest. Сначала прочитай папку Obsidian в проекте, особенно 01_PROJECT.md, 02_CURRENT_STATUS.md, 03_ROADMAP.md и 05_DECISIONS.md. Затем проверь актуальное состояние файлов проекта. Не повторяй уже реализованное. Моя текущая задача: [описать задачу]. Реализуй изменение, проверь сборку и обнови документацию Obsidian.
```

## Работа над разделом «Миссия»

```text
Продолжаем развивать раздел «Миссия» EduQuest. Прочитай Obsidian/01_PROJECT.md и Obsidian/02_CURRENT_STATUS.md. Раздел должен связывать выбранные качества ребёнка с навыками, мирами, проектами и действиями дня. ИИ-наставника пока не добавляй. Реализуй: [задача].
```

## Создание нового материала

```text
Создай новый материал для раздела «Миссия» EduQuest. Материал должен развивать выбранные качества через практическую экспедицию, а не через школьный урок. Используй цикл: история → гипотеза → создание → испытание → ошибка → улучшение → объяснение → помощь другому. Добавь интересные визуальные подсказки, но не давай готовое решение. Название материала: [название]. Навыки: [список].
```

## Деплой

```text
После реализации покажи изменённые файлы, проверку сборки и команды публикации. GitHub: sychev23021983-design/eduquest. Сервер: /root/eduquest. Используй: cd /root/eduquest && git fetch origin && git reset --hard origin/main && docker compose up -d --build --force-recreate.
```

## Проверка без изменения кода

```text
Прочитай Obsidian в проекте и сделай аудит текущего статуса. Сравни реализованное с ROADMAP, найди расхождения, не вноси изменения без отдельного согласования.
```

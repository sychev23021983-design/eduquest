# Текущий статус

## Реализовано

### Раздел «Миссия»

- Добавлен маршрут `/mission`.
- На главном экране добавлена кнопка `🧭 Миссия`.
- Выбор качеств личности от 3 до 5.
- Карточки качеств используют изображения из `frontend/public/mission-icons/`.
- После выбора показывается профиль развития и связанные навыки.
- Выбор сохраняется в `localStorage`.
- Добавлены вкладки: Обзор, Материалы, Неделя, Сегодня, Совет исследователей.
- Добавлены миры года и прогресс по ним.
- Добавлена экспедиция квартала.
- Добавлены три задачи дня и выбор уровня энергии.

### Материалы миссии

Создан первый материал:

**«Построй самый прочный мост»**

Включает:

- гипотезу;
- визуальную подсказку с четырьмя типами мостов;
- создание первой конструкции;
- испытание монетами;
- фиксацию результата;
- улучшение конструкции;
- повторное испытание;
- объяснение вывода;
- совет другому строителю.

Иллюстрация: `frontend/public/mission-icons/bridge-types.png`.

Добавлены карточки материалов 2–10 в разделе «Миссия → Материалы»:

- Изобрети приспособление для рабочего стола.
- Спаси яйцо.
- Придумай машину, которая движется сама.
- Разгадай правило последовательности.
- Найди ошибку в инструкции.
- Научи младшего.
- Освой навык за семь дней.
- Командная экспедиция.
- Большой финальный проект.

У каждой карточки есть описание задания, развиваемые навыки, визуальная подсказка и кнопка входа. Детальные интерактивные сценарии пока полноценно реализованы только для моста; остальные карточки подготовлены как следующий слой контента.

### Обновлённые уроки русского языка

Первый раздел получил новые названия миссий:

- Миссия 1. Карта русского языка.
- Миссия 2. Собери понятное сообщение.
- Миссия 3. Расшифруй слово.
- Миссия 4. Спаси текст от ошибок.
- Миссия 5. Оживи газетный текст.

В уроки добавлены сюжетные входы и описание новой механики. Полное разделение урока на отдельные интерактивные этапы пока не завершено.

## Проверки

- Frontend production build проходит через `npm run build`.
- Backend-файлы проверялись через `py_compile`.

## Ограничения текущей версии

- Данные «Миссии» пока хранятся только в браузере через `localStorage`.
- Выбор качеств не синхронизируется между устройствами.
- Навыки пока не получают реальный прогресс от материалов миссии.
- Материалы пока зашиты во frontend, а не хранятся в backend.
- Фотографии результатов проектов пока не загружаются.
- ИИ-наставник не реализован и пока не нужен.

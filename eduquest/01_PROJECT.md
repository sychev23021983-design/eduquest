# EduQuest — описание проекта

EduQuest — образовательное приложение для детей, которое помогает не только получать знания, но и учиться думать, вспоминать, применять знания, создавать проекты и объяснять другим.

## Продуктовая идея

EduQuest должен развиваться от контент-платформы к системе формирования устойчивых навыков обучения.

Основной цикл обучения:

```text
Интерес → Исследование → Active Recall → Применение → Проект → Повторение → Объяснение → Новый уровень
```

ИИ-наставник пока не используется. Все задания должны работать без ИИ: открытые ответы, фиксированные подсказки, практические задачи, проекты и самооценка.

## Основные разделы

### Предметы

Школьные и академические материалы: русский язык, математика, академия исследователей и другие направления.

### Навыки

Набор практических задач для развития отдельных навыков: логика, критическое мышление, планирование, коммуникация и т.д.

### Миссия

Отдельный раздел рядом с «Навыками». Он отвечает на вопрос: «Каким человеком я хочу стать?»

Структура миссии:

```text
Выбранные качества → рекомендуемые навыки → миры года → квартальный проект → недельные шаги → три задачи дня
```

В разделе есть:

- выбор 3–5 качеств личности;
- профиль развития;
- миры года;
- экспедиция квартала;
- материалы для миссии;
- план недели и дня;
- управление энергией;
- Совет исследователей.

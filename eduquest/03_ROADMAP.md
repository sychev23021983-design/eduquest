# План развития

## Ближайший этап — сделать «Миссию» настоящей системой

1. Вынести качества, навыки, миры и материалы из `MissionPage.jsx` в отдельные структуры данных.
2. Добавить backend-таблицы для профиля ребёнка и выбора качеств.
3. Связать выбранные качества с рекомендациями навыков.
4. Сделать карточку «Навыки для моей миссии» на странице «Навыки».
5. Перенести материалы миссии в backend и сделать их редактируемыми родителем.
6. Добавить сохранение прохождения материалов на сервере.
7. Добавить загрузку фотографии результата проекта.

## Материалы для выбранного профиля

Следующие экспедиции:

- Спаси яйцо.
- Изобрети приспособление для рабочего стола.
- Придумай машину, которая движется сама.
- Разгадай правило последовательности.
- Найди ошибку в инструкции.
- Научи младшего.
- Освой маленький навык за семь дней.
- Командная экспедиция.
- Большой финальный проект.

Каждый материал должен иметь цикл:

```text
История → Гипотеза → Создание → Испытание → Ошибка → Улучшение → Объяснение → Помощь другому
```

# Принятые решения

## Продуктовые

- EduQuest развивает мышление, память, применение и создание, а не только прохождение уроков.
- «Миссия» — отдельный раздел рядом с «Навыками».
- Ребёнок выбирает качества личности, а не профессию.
- Выбор качеств не является диагнозом и не фиксирует ребёнка в одном профиле.
- Рекомендуемые навыки должны предлагаться, но не становиться обязательными.
- Материалы миссии должны заканчиваться результатом: создано, проверено, улучшено, объяснено или применено.
- Воскресенье должно оставаться свободным от обязательных задач.

## Технические

- ИИ-наставник пока не реализуется.
- На первом MVP раздел «Миссия» работает без нового backend и хранит данные в `localStorage`.
- Новые изображения для миссии хранятся в `frontend/public/mission-icons/`.
- При обновлении существующих seeded-уроков нужно использовать `seed_lesson_regenerate`, а не только `seed_lesson_if_missing`.
- Изменение frontend требует Docker-сборки с `--build`; при проблемах с кэшем использовать `--no-cache`.
- Не использовать `git reset --hard` без понимания последствий; на сервере он допустим, если GitHub является источником истины и локальные серверные коммиты не нужны.
